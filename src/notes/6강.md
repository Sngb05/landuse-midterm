# 6강. 도시활동 수요분석
> 용도별 토지수요는 '규모(a) ÷ 밀도(d)'로 구한다. 규모를 정하는 인구추정은 과거추세연장법(등차·등비·최소제곱·지수·수정지수·로지스틱)과 조성법(생잔모형)·순인구이동·종합모형으로 하고, 산업·고용·인구는 Lowry 모형으로 연결한다. 공간 단위는 Perry 근린주구와 생활권, 경계는 레일리 법칙, 위계는 크리스탈러 중심지이론으로 나눈다.
> 페이지 표기는 이미지 파일 번호(pNN) 기준(슬라이드에 쪽번호 없음). PPTX를 PDF로 바꾼 자료라 손필기는 없고, 빨간 글씨·밑줄은 슬라이드 원본 강조임.
> 수식은 원문 표기를 그대로 옮겼고, 원문에 오타나 앞뒤 안 맞는 곳은 [ ] 안에 따로 적음.

## 핵심 정리

### 0. 도시활동유형과 토지이용수요 (p4)
- 그림 <인구 및 경제활동 유형과 용도별 토지수요 관계> (p4)
  - **인구** → 녹지, 주거, 상업
  - **경제활동** → 3차산업, 4·5차산업, 2차산업
    - 3차산업 → 상업, 업무 / 4·5차산업 → 업무 / 2차산업 → 업무, 공업
- 자료원 (p30)
  - **인구 및 가구**: **주거용** 토지수요 추정의 기초. 인구주택센서스, 주민등록인구자료 이용. 가구수, 연령별 인구구성, 주민등록인구이동, 가구당 가구원수
  - **경제활동**: **공업, 상업, 업무용** 토지수요 추정의 기초. 광공업통계, 도소매업통계, 지역상공회의소 자료 이용. 고용자수, 경제활동인구, 임금 등
  - KOSIS 국가통계포털 (http://kosis.kr/index/index.jsp)

### 1. 용도별 토지이용 수요추정방법 3단계 (p5)
- **1단계**: 목표년도의 인구 및 경제활동 **규모(a)** 예측 (p5)
- **2단계**: 목표년도의 토지이용 **밀도(d)** 기준 설정 (p5)
- **3단계**: 용도별 토지이용 수요 **S = a/d** 추정 (p5)
- **총밀도 vs 순밀도** (p5, 슬라이드엔 단어만 있음)
  - (보충) 총밀도 = 인구 ÷ 도로·공원 등 공공용지까지 포함한 전체 면적, 순밀도 = 인구 ÷ 순수 택지(주거용지) 면적. 7강의 총주거용지 = 순주거용지 ÷ (1 − 공공용지율) 계산과 같은 구분

### 2. 과거추세 연장법 (p6~p13)
- 과거의 인구변화 자료를 바탕으로 미래 인구를 예측. **대수적방법 vs 회귀분석법**. 함수모양은 매우 단순: `Pₜ = f(t)` (p6)
  - (보충) 등차·등비·지수처럼 두 시점 값으로 바로 계산하면 대수적 방법, 최소제곱법처럼 전체 자료로 직선을 맞추면 회귀분석법
- 그래프 4종 (p7). 실선 = 과거, 세로선 이후 점선 = 추정
  - **등차**: 직선
  - **등비 or 지수함수**: 아래로 볼록, 점점 가팔라짐(급증)
  - **수정지수함수 or 곰페르츠**: 처음 빨리 늘다가 증가가 둔화
  - **로지스틱**: S자. 완만 → 급증 → 상한에 수렴

#### 2-1. 등차급수 (p8)
- 안정된 인구증가율을 가진 도시에 적합 / 인구변화가 일정하게 일어나는 **수도권 인근 중소도시**에 적용 가능 / 연도에 따라 인구증감이 교차하는 도시에는 적용이 어려움 (p8)
- 원문 수식 (p8)
  - `Pₙ = Pₒ(1 + rn)`
  - `r = (1/n′)(P′ₙ − P′₀)`
  - Pₙ: 목표연도 인구 / Pₒ: 기준연도 인구 / **r: 인구 증가량** (빨간 글씨 "증가량ㅊ") / n: 기준연도로부터 목표연도까지의 경과연수(n−o)
  - Pₙ′: 과거 통계자료상 최종연도 인구 / Pₒ′: 과거 통계자료상 초기연도 인구 / n′: 초기연도- 최종연도
  - [원문 확인 필요] r = (1/n′)(P′ₙ − P′₀)는 연평균 증가 **인원**(명/년)인데 `Pₒ(1 + rn)`에 그대로 넣으면 값이 맞지 않음. 증가량으로 쓰면 `Pₙ = Pₒ + rn`, 식을 그대로 쓰려면 r = (P′ₙ − P′₀) ÷ (n′·P′₀)(증가율). n′도 원문은 '초기연도-최종연도'지만 실제로는 최종연도 − 초기연도(양수)

#### 2-2. 등비급수 (p9)
- **인구증가 비율이 일정**한 도시에 적합 / **신흥공업도시와 같이 급성장도시**에 적용 가능 / 연도에 따라 인구증감이 교차하는 도시에는 적용이 어려움 (p9) ★기출2024 ★기출2025 (성장 초기 급증 → 지수 계열)
- 원문 수식 (p9)
  - `Pₙ = Pₒ(1 + r)ⁿ`
  - `r = (Pₙ′ / Pₒ′)^(1/n′) − 1`
  - **r: 인구 증가율** (빨간 글씨), 나머지 기호는 등차와 같음

#### 2-3. 최소제곱법 (선형모형: 등차급수랑 유사) (p10)
- **대부분의 도시**에 적용 가능 / **비교적 정확**한 인구추정이 가능 / 연도에 따라 **인구증감이 교차하는 도시에는 적용 가능** (p10)
- 원문 수식 (p10)
  - `y = a + bx`, `a = Σyᵢ / n`, `b = Σxᵢyᵢ / Σxᵢ²`
  - y: 목표연도(추정)인구 / x: 기준연도로부터 경과연도 / n: 자료 개수 / a: 기준연도의 이론적 인구 / b: 단위기간의 절대인구 증가수
  - 이때 **x의 합계가 0이 되도록 중간년도를 0**으로 하고 과거는 −1, −2, … 로 설정 (그래서 a, b 식이 위처럼 간단해짐)

#### 2-4. 지수함수 (p11)
- **인구가 연속적으로 변한다는 가정** 하에 사용 / **짧은 기간, 순간단위의 변화**까지도 분석 가능 / 연도에 따라 인구증감이 교차하는 도시에는 적용이 어려움 (p11)
- 원문 수식 (p11)
  - `Pₙ = Pₒe^(rn)`
  - `r = (1/n′) ln(Pₙ′ / Pₒ′)`
  - r: 인구 증가율, 나머지 기호는 등차와 같음

#### 2-5. 수정 지수함수 (p12)
- **인구성장의 한계**(K)가 있다고 가정 / **인구성장률이 지속적으로 둔화**된다고 가정 (p12)
- 원문 수식 (p12)
  - `Pₙ = K − [(K − P₀)·λⁿ]`
  - `λ = (1/n) Σᵢ₌₁ⁿ { (K − Pᵢ) / (K − Pᵢ₋₁) }`
  - K: 인구성장한계 (**연구자 설정값**)
  - Λ(λ): 인구증가 결정지수 (현재인구와 상한인구(K)의 차이에 대한 고정비율
- 곰페르츠는 p7 그래프 이름에만 나옴(식 없음)

#### 2-6. 로지스틱 곡선 (p13)
- **대도시권의 인구를 어느 상한선까지 강력히 통제**하고자 할 때 사용 / 비교적 정확한 인구추정 / **인구목표와 성장속도와의 관계**를 분석하는데 유효하게 쓰임 (p13) ★기출2024 ★기출2025 (가장 장기적인 추세 → 로지스틱)
- 원문 수식 (p13)
  - 식(1): `Pₙ = K / (1 + e^(a+bn))`
  - `Pₙ = K / (1 + eᵃ · e^(bn))`
  - a: 기준년도(0) 인구와 인구한계를 이용하여 구함 → 식(2): `eᵃ = K / (P₀ − 1)`, `a = ln(K/P₀ − 1)`
    - [원문 확인 필요] 식(2)는 분모가 'P₀ − 1'로 찍혀 있지만, 바로 옆 a 식과 맞추면 **eᵃ = K/P₀ − 1**이 맞음
  - b: 식(2)를 식(1)에 대입하여 구함 → `b = (1/n) ln[ (K/Pₙ − 1) / (K/P₀ − 1) ]`

### 3. 인구와 가구 통계 (p15~p17, p21~p22)
- **세계인구 증가 속, 한국 인구 감소**: 한국인구는 최대 **5200만명(2024)**, **2072년 3600만명**으로 감소 (자료: 통계청 보도자료 2024.9.23) (p15)
  - 그래프: 한국 '70 32백만 → '00 47백만 → '24 52백만 → '50 47백만 → '72 36백만 / 세계 36.9억(1970) → 61.7억(2000) → 81.6억(2024) → 96.6억(2050) → 102.2억(2072) (p15)

### 5. 자연증감: 조성법 (생잔모형; cohort-survival method) (p19~p20) ★기출2024 ★기출2025
- 인구를 **연령별로 구분**, **출산율과 생존율**(1−사망률)을 이용하여 장래 인구 예측 (p19)
  - survival rate (생존율) / birth rate (출생률)
  - 위의 두 비율의 동일가정은 추정치가 있으면 변한다고 가정할 수도 있음 (p19)
- 원문 수식 (p19)
  - `P_N(i+1; j)ₜ = s(i; j)ₖ · P_T(i; j)ₜ₋ₖ,  i = 1, 2, …, m−1;  j = 남, 여`
  - `P_N(1~5세; j)ₜ = b(j)ₖ · P_T(16~45tp; j = 여)ₜ₋ₖ`
  - [원문 '45tp'는 '45세'를 영문 자판으로 친 오타로 보임(ㅅ=t, ㅔ=p)] → 출생아(1~5세) = 출생률 × 가임 여성(16~45세) 인구
  - (보충) P_N: 자연증감만 반영한 추정인구, P_T: 실제(총)인구, s: 생존율, b: 출생률, i: 연령계층, j: 성별, t−k → t: k년 뒤 한 연령계층씩 올라감
- 생잔모형 예시: **인구피라미드 1960년 = 피라미드형, 2010년 = 방추형** (자료: 인구주택총조사 보도자료, 통계청) (p20)

### 7. 사회적 증감: 순인구이동 (net migration) (p24)
- **연령별 실제인구와 자연증감인구의 차 = 순인구이동량** (p24)
  - `P_M(i; j)ₖ ≡ P_T(i+1; j)ₜ − P_N(i+1; j)ₜ`
- 순인구이동의 규칙성을 찾기 위해 **2가지 방법** 사용 (p24)
  - **잔차기법 (residual technique)**: 순인구이동의 **절대량이 일정**
    - `P_M(i; j)ₖ ≡ P_T(i+1; j)ₜ − P_N(i+1; j)ₜ ≈ a(상수)`
  - **비율기법 (ratio technique)**: 자연증가인구 대비 순인구이동인구의 **비율이 일정**
    - `m(i : j)ₖ = P_M(i+1 : j)ₜ / P_T(i+1 : j)ₜ ≈ a(상수)` (빨간 글씨)
    - [원문 확인 필요] 설명은 '자연증가인구 대비'인데 식의 분모는 P_T(실제 총인구)이고, p26도 '총인구대비 사회증감'이라 적음

### 8. 종합적 모형 (p26)
- **자연증감과 사회적 증감(비율기법)을 종합적으로 고려**하여 연령별 인구를 예측 (p26)
- 원문 수식 (p26)
  - `P_T(i+1; j)ₜ = s(i; j)ₖ · [1 + m(i; j)ₖ] · P_T(i; j)ₜ₋ₖ,  i = 1, 2, …, m−1;  j = 남, 여`
  - `P_T(1~5세; j)ₜ = b(j)ₖ · [1 + m(i; j)ₖ] · P_T(16~45tp; j = 여)ₜ₋ₖ` (m(i; j)ₖ에 빨간 밑줄)
  - 화살표 설명: **사회적 증감부분 (총인구대비 사회증감)** `m(i : j)ₖ = P_M(i+1 : j)ₜ / P_T(i+1 : j)ₜ ≈ a(상수)`
- 정리: 조성법 식에 [1 + m]을 곱해 전입·전출까지 반영 = 생존율(자연) × (1 + 순이동비율)(사회)

### 9. Lowry Model (p28~p29)
- **1964 – Ira S. Lowry** / **Spatial interaction model** (p28)
- Modeling innovations (p28)
  - Sub-regional forecasts were generated to control to regional totals (하위지역 예측치를 지역 전체 합계에 맞춤)
  - **Employment, population, and transportation were combined in one model** (고용·인구·교통을 한 모형에 결합)
- 모형 흐름도 (p29): **Basic Sector → Demand for Labor → Size of Population → Demand for Non-Basic → (다시) Demand for Labor** (순환)
  - Distribution of basic jobs across zones is given (기반산업 일자리의 지역별 분포는 주어짐)
  - Travel time (network) is given (통행시간·교통망은 주어짐)
  - Model generates population and non-basic employment by zone (모형이 지역별 인구와 비기반 고용을 산출)
- 주요질문 답: **기반산업(Basic Sector)이 노동수요(고용)를 만들고 → 그 고용이 인구 규모를 결정하고 → 인구가 비기반산업(서비스) 수요를 만들고 → 비기반산업이 다시 노동수요를 늘리는** 순환관계 (p29)
  - (보충) 기반산업 = 지역 밖으로 수출하는 산업(제조업 등), 비기반산업 = 지역 주민을 상대하는 서비스·소매업. 이 순환이 반복되며 승수효과가 생김

### 10. 근린주구 (Neighborhood Unit) (p31~p33)

### 12. 생활권 및 경제활동권의 경계: 레일리 법칙 (p36~p37) ★기출2024 ★기출2025
- **레일리의 소매인력법칙 (Reilly's law of retail gravitation)** (p36)
  - 가정1: 모든 사람이 이왕이면 **가까운 거리**에서 구매하려 함
  - 가정2: 모든 사람이 상대적으로 **규모가 큰 중심지**에서 상품을 구입하려 한다
  - **경계면에 있는 사람은 각 중심지를 이용할 확률이 50%**
  - **2개 도시의 흡입력은 인구에 비례, 거리의 제곱에 반비례**
- **원문 공식 (p37)**: `M_ab = D_ab / (1 + √(P_b / P_a))`
  - M_ab: a에서 경계(분기점)까지 거리, D_ab: 두 도시 간 거리, P_a·P_b: 두 도시 인구 (그림에서 M_ab는 a로부터 잰 거리)
  - **슬라이드 예제 (p37)**: a 250,000명, b 100,000명, 거리 75km → `M_ab = 75 / (1 + √(100,000/250,000))`, **M_ab = 45.9** → a로부터 **45.9km**, b로부터 **29.1km**
  - 확인: √0.4 ≈ 0.632 → 75 ÷ 1.632 ≈ 45.94, 75 − 45.94 ≈ 29.06
- **기출 풀이 (이 공식으로 검산, 둘 다 기출 정답과 일치)**
  - 2024: A 100만, B 36만, 20km → M = 20 ÷ (1 + √(36/100)) = 20 ÷ (1 + 0.6) = 20 ÷ 1.6 = **A로부터 12.5km** (B로부터 7.5km) ★기출2024
  - 2025: A 100만, B 64만, 36km → M = 36 ÷ (1 + √(64/100)) = 36 ÷ (1 + 0.8) = 36 ÷ 1.8 = **A로부터 20km** (B로부터 16km) ★기출2025
- 요령: 거리를 재는 기준 도시(a)를 분모 아래쪽(P_a)에, **상대 도시 인구를 루트 안 위쪽**(P_b)에 넣음. 경계는 **작은 도시 쪽**에 가까워짐(큰 도시의 영향권이 더 넓음)
- (보충) 이 분기점 공식은 Reilly(1931)의 법칙에서 Converse(1949)가 끌어낸 식으로 알려져 있음

### 13. 경제활동권: Christaller의 중심지이론 (central place theory) (p38~p39)
- 도시와 **배후지**간의 관계 모형화 (p38)
- **하위의 중심지는 상위의 중심지에 포섭**됨 (p38)
- **상위중심지는 하위중심지의 상품 모두 취급** (p38)
- **같은 위계의 상권경계는 육각형모양** (p38)
- 그림 (p39): 제1차 중심지(**G**)의 시장지역 경계(굵은 실선, 가장 큰 육각형) ⊃ 제2차 중심지(**B**)의 시장지역 경계(점선) ⊃ 제3차 중심지(**K**)의 시장지역 경계(가는 실선, 가장 작은 육각형)
  - (보충) 육각형이어야 원형 상권처럼 빈틈(서비스 공백)이나 겹침 없이 평면을 채울 수 있음

### 참고: 섹션 번호
- p3 간지는 'I. 인구 및 경제활동 분석', p5~p26 머리말은 'II. 인구 및 경제활동', p27 간지는 'II. 도시활동 분석', p4·p28~p39 머리말은 'I. 도시활동 분석'으로 번호가 서로 엇갈림. 내용상 순서는 ① 인구 및 경제활동 분석(p4~p26) → ② 도시활동 분석(Lowry·생활권·레일리·중심지, p28~p39)

## 예상 문제
1. **(빈칸·계산) 레일리 법칙으로 도시영향권 경계를 구하시오.** (2024·2025 연속 출제, 숫자만 바뀜)
   - 예: A 90만, B 40만, 거리 50km → 50 ÷ (1 + √(40/90)) = 50 ÷ (1 + 0.667) = 50 ÷ 1.667 = **A로부터 30km**. 원리: 흡입력은 인구에 비례, 거리의 제곱에 반비례하고 경계에서는 두 도시 이용 확률이 50%로 같음
2. **인구추정방식(과거추세연장법과 조성법)의 차이를 설명하시오.** (주요질문)
   - 과거추세연장법은 과거 총인구 자료를 시간의 함수 Pₜ = f(t)로 연장해 미래 총량을 예측한다(등차, 등비, 최소제곱, 지수, 수정지수, 로지스틱). 함수가 단순하지만 총량만 예측해 인구변화 요인을 분석하지 못한다. 조성법(생잔모형)은 인구를 연령별로 나누고 출산율과 생존율(1−사망률)을 적용해 연령별 인구를 예측한다. 그래서 주택·학교·노인시설 수요 예측에 직접적인 시사점을 준다. 사회적 증감은 순인구이동(잔차기법·비율기법)으로 더하고, 둘을 합친 것이 종합적 모형이다.
3. **과거추세연장법의 모형별 특징을 비교하시오.** (비교표)
   - 등차: 안정된 증가율, 수도권 인근 중소도시 / 등비: 증가 비율 일정, 신흥공업도시 같은 급성장도시 / 최소제곱: 대부분 도시, 비교적 정확, 증감 교차 도시에도 가능 / 지수: 연속 변화, 짧은 기간 분석 / 수정지수: 성장한계 K, 성장률 둔화 / 로지스틱: S자, 대도시권 인구를 상한선까지 통제, 가장 장기적인 추세. 등차·등비·지수는 증감이 교차하는 도시에 적용이 어렵다.
4. **Lowry 모형에서 산업, 고용, 인구의 관계를 설명하시오.** (주요질문)
   - Ira S. Lowry(1964)의 공간상호작용모형으로, 고용·인구·교통을 한 모형에 결합했다. 기반산업이 노동수요를 만들고, 고용이 인구규모를 정하며, 인구가 비기반산업 수요를 만들고, 비기반산업이 다시 노동수요를 늘리는 순환구조다. 기반산업 일자리 분포와 통행시간(교통망)을 주면 지역별 인구와 비기반 고용이 산출된다.
5. **근린주구이론의 원전과 우리나라 생활권 구분방법을 설명하시오.** (주요질문)
   - 원전은 Clarence Perry의 근린주구다. 초등학교 1개를 중심으로 한 반경 1/4 mile 도보권(약 160 acres)이며, 6요소는 규모, 경계, 공원(면적의 10%), 공공건축물(커뮤니티센터), 근린상가(주변부 교통 결절점), 내부가로망이다. 우리나라는 소생활권(행정동, 2~3만, 초·중학교 학군, 근린지구 중심), 중생활권(2~4개 소생활권, 10만, 중·고교 학군, 커뮤니티), 대생활권(구단위, 50만, 부도심권 중심)으로 나누며 구분은 상대적이다.
6. **크리스탈러 중심지이론의 주요 내용을 쓰시오.** (주요질문)
   - 도시와 배후지의 관계를 모형화했다. 하위 중심지는 상위 중심지에 포섭되고, 상위 중심지는 하위 중심지의 상품을 모두 취급한다. 같은 위계의 상권경계는 육각형이며, 제1차(G) ⊃ 제2차(B) ⊃ 제3차(K) 중심지의 시장지역이 겹쳐진 위계 구조를 이룬다.
